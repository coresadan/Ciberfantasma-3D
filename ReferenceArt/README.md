# Referencias visuales

Copias de trabajo seleccionadas del juego 2D original. Se conservan aqui para modelado, materiales y comprobacion de silueta; los archivos originales permanecen en `Ciberfantasma Bros/assets`.

Estas imagenes no se importan directamente como sprites del juego final. El personaje 3D debe mantener:

- Mascara oscura de lectura inmediata.
- Acentos verdes de codigo libre.
- Silueta chibi heroica de unas 2,6 cabezas, con cabeza grande, cuerpo compacto, manos expresivas y botas anchas.
- Guantes y emisor de pulso legibles desde la camara lateral.
- Superficies negras diferenciadas mediante metal, tejido tecnico y goma, no mediante negro plano.

El fondo `corporate-city.png` es una referencia de composicion y paleta. El escenario final se construira con geometria, materiales PBR, luces y profundidad reales.

## Referencia canonica del protagonista

- `ciberfantasma-chibi-turnaround-v1.png`: frontal, lateral, espalda y primer plano de mascara para modelado 3D.
- `ciberfantasma-chibi-idle-final.png`: proporcion y simpatia de la version jugable original.

Las referencias de proporcion atletica se conservan unicamente para consultar piezas de armadura. No definen la silueta final.
